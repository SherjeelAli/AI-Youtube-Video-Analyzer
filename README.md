# 🎥 AI YouTube Video Analyzer

An AI-powered YouTube Video Analyzer built with **Python, Streamlit, Agno, and Google Gemini**. It analyzes YouTube videos through their transcripts and provides AI-generated insights and answers.

## 🚀 Live Demo

🔗 [Streamlit App](https://ai-youtube-video-analyzer-4yfgygyyguuyqtnzp6bard.streamlit.app/)

## ✨ Features

* 🎥 Analyze YouTube videos using their URLs
* 📝 Extract YouTube transcripts
* 🤖 AI-powered analysis using Google Gemini
* 💬 Ask questions about video content
* 🌐 Interactive Streamlit interface

## 🛠️ Tech Stack

* Python
* Streamlit
* Agno
* Google Gemini
* YouTube Transcript API
* DuckDuckGo
